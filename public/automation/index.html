M3E CANVAS NEXT / AUTOMATION

让画布可读取，
让修改可确认。

浏览器内画布工具、项目文件 CLI 和进程式 MCP 是三个不同入口。请按对应步骤验证，避免把文件处理能力误认为实时画布控制。

打开画布

1 · 内置浏览器中的画布工具

在支持站点工具的 ChatGPT 内置浏览器中，打开画布顶层页面。工具注册在画布页，此说明页不注册工具。账号、模型和浏览器的支持情况会影响可用性。

  • get_canvas_document：读取当前画布项目及 revision。
  • get_canvas_prompt：读取当前项目的提示词。
  • preview_canvas_document：传入完整 document 和读取时的 expectedRevision，暂存候选项目并展示完整 JSON 预览，等待页面上的确认操作。画布版本不符时拒绝提交。

工具出现在站点工具列表并能实际调用，才代表连接成功。网页可打开、构建通过或检测到 API 属性，都不能单独证明工具可用。

  1. 先备份当前项目；读取画布文档（保留 revision）和提示词。
  2. 通过工具提交候选项目预览，确认当前文档尚未被替换。
  3. 在页面检查后点击 Apply candidate 确认导入，再次读取文档，核对变更。
  4. 提交无效候选输入，确认得到错误且画布未变。

ChatGPT 站点工具说明

当前工具面板为英语。手动 Apply 后，原编辑器可能按主题加载已支持的 Google Fonts；工具不接受新图片资源。候选只显示 JSON，不加载候选资源。

2 · CLI：处理显式项目文件

在源码目录使用 package.json 指定的 Node 版本。以下示例项目包含空白 Home 画布和一段固定提示词，便于核对输出。

下载示例项目 JSON

npm ci
npm run build:headless
node dist-headless/cli/main.js validate sample-project.json
node dist-headless/cli/main.js prompt sample-project.json --lang en

第二条 CLI 命令的预期提示词：

M3E Canvas automation sample.

CLI 只读取传入文件或 stdin，不读取浏览器存储，也不会自动同步已打开的画布。分享链接包含项目内容且未加密，发送前请检查。

3 · MCP：在宿主内启动 stdio 服务

node /absolute/path/to/checkout/dist-headless/cli/mcp.js

经授权在 MCP 宿主中配置绝对路径，并验证初始化和工具列表。可用工具为 validate_project、generate_prompt、create_share_link；输入是显式项目 JSON。

这是本地进程 stdio MCP，不是网页 HTTP 服务或浏览器站点工具。访问本网站不会安装 skill、配置 MCP 宿主，或启动你电脑上的进程。源码中的 skills/m3e-canvas/SKILL.md 提供文件交换流程。

验证结果应记录浏览器版本、模型、实际调用与返回值。未完成真实站点工具调用前，不应宣称已验证 ChatGPT 内置浏览器兼容性。
